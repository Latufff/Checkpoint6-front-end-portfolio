# Portfólio — Lucas Latuf

## Como executar
1. Extraia a pasta do projeto.
2. Mantenha `index.html`, `styles.css`, `script.js` e a pasta `assets/` juntos.
3. Abra `index.html` no navegador ou publique a pasta em um serviço estático, como GitHub Pages, Netlify ou Vercel.
